# MENU-QR FİKİR HAVUZU
# Mevcut ürünü bozmadan: “bak bunu koysak çok satar” notları
# Sen oku, ele, sırala. Tekrarlayan / zaten var olanlar bilinçli yazılmadı (alerji filtresi, temalar, QR paket, kampanya, hikâye, toplu çeviri zaten var).

================================================================================
A) MÜŞTERİ TARAFİ — “WOW, bu menü farklı”
================================================================================

2. Baharat / acılık seviyesi filtresi
   - Üründe 0–3 acı biber; müşteri “az acı” seçince sert olanlar düşer.
   - Kebap / Asya / Meksika işletmelerine birebir.

3. Kalori / protein hedefi
   - “Bugün 600 kalori altı” veya “yüksek protein” hızlı filtre.
   - Fitness cafe / healthy bowl yerleri bayılır.

5. Masa bazlı garson çağır / hesap iste
   - QR’da masa no zaten geliyor; tek tuş “Garson” / “Hesap” → admin’e anlık bildirim.
   - Restoranlar için en net “bunu isterim” özellik.

6. Sipariş notu / “bu ürünü istiyorum” sepet (sipariş motoru olmadan)
   - Sepete ekle → masa no + not → WhatsApp / garson paneline düşer.
   - Tam POS’a girmeden “hafif sipariş” satışı.

8. Ürün “benzer lezzetler” + “bununla iyi gider”
   - Related products var; kurallı çapraz satış (burger → patates, kahve → tatlı).

9. Stok / “tükendi” anlık rozeti
   - Admin tek tık “tükendi”; menüde gri + “bugün yok”.
   - Mutfak stresi azalır, müşteri kızmaz.

10. Günün menüsü / saatlik menü
    - Öğle 12–15 sadece öğle setleri; gece farklı kategori.
    - Otel / büyük cafe için premium eklenti.

13. Sesli menü / ekran okuyucu dostu mod
    - Büyük yazı, yüksek kontrast, az animasyon (erişilebilirlik = ihale/otel artısı).

14. Menüde “hazırlama süresi”ye göre sırala
    - “Acele” → 10 dk altı ürünler üste.

16. “Şefin notu” kısa video (15 sn) ürün detayında
    - Hikâye altyapısı var; ürüne özel mikro video premium.

================================================================================
B) ADMİN TARAFİ — “Bunu her gün kullanırım”
================================================================================

22. Tek tık “tükendi / geldi” ürün paneli (mutfak tablet modu)
    - Büyük butonlar, fotoğraflı grid; garson/aşçı kullanır.

23. Fiyatı toplu güncelle (% zam, yuvarla)
    - “Tüm kahvelere %15” → önizle → uygula.
    - Enflasyon döneminde herkes ister.

24. Happy hour / saatlik fiyat
    - 17–19 biralar X TL; kampanya motorunu zamana bağla.

27. Fotoğraf AI önerisi / arka plan temizle
    - Ürün yüklerken “arka planı temizle + ışığı düzelt” (ücretli kota).

29. Diyet bayrakları UI (vegan / vejetaryen / GF / diyabetik)
    - Schema hazır; form’a 4 checkbox.

30. “Boş çeviri” kırmızı uyarı dashboard’da
    - Dil paketı olanlara: “12 üründe İngilizce eksik” → toplu çeviriye at.

32. Masa ısı haritası
    - Hangi masa QR’sı ne kadar tıklandı; doluluk / popüler salon.

34. Excel / CSV menü içe aktar
    - 200 ürünlü yer 1 günde geçer. Satış kapatıcı özellik.

39. Etkinlik modu: düğün / özel gece menüsü zamanla aç-kapa
    - Kampanya + takvim.

================================================================================

================================================================================
D) BÜYÜME / SATIŞ / İŞ MODELİ
================================================================================

52. Abonelik + eklenti mağazası (kod yerine ödeme)
    - Aylık / yıllık; eklenti aç/kapa faturalı.

55. Satış demosu: admin’de “müşteriye göster” full ekran tur
    - Eklentiler kilitli ama önizlemeli (zaten demo data var; tur senaryosu ekle).

56. Referans QR: “bu sistemi yapan Güzel Teknoloji” küçük footer (ücretsiz planda)
    - Ücretli planda kalkar = upsell.

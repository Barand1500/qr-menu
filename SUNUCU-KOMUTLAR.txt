  MENU QR — SUNUCU KOMUTLARI (CloudPanel SSH)
  Domain: https://menu.guzelteknoloji.com
  Port: 3008
====================================================

ÖN KOŞUL
--------
- Dosyalar şurada olmalı:
  htdocs/menu.guzelteknoloji.com/
  (dist, public, prisma, uploads, package.json, .env)

- .env dosyasını elle düzelttin. Tamam.
  Şifrede ! varsa URL içinde %21 olmalı.


----------------------------------------------------
1) SITE KLASÖRÜNE GİR
----------------------------------------------------
cd ~/htdocs/menu.guzelteknoloji.com

Ne işe yarar?
  Terminali proje klasörüne götürür.
  Sonraki komutlar burada çalışır.


----------------------------------------------------
2) PAKETLERİ KUR
----------------------------------------------------
npm install --omit=dev

Ne işe yarar?
  package.json içindeki bağımlılıkları indirir.
  node_modules klasörünü oluşturur.
  --omit=dev = sadece canlıda lazım olan paketler.


----------------------------------------------------
3) VERİTABANI + İLK VERİ
----------------------------------------------------
npm run setup

Ne işe yarar?
  1. Prisma client üretir
  2. MySQL tablolarını oluşturur
  3. Seed ile örnek / admin verisini yükler


----------------------------------------------------
4) UYGULAMAYI BAŞLAT
----------------------------------------------------

SEÇENEK A — CloudPanel’den başlatıyorsan:
  Panel → Node.js → Start / Yeniden Başlat
  (SSH’de npm start ÇALIŞTIRMA, port çakışır)

SEÇENEK B — SSH’den test için:
npm start

Ne işe yarar?
  node dist/index.js çalışır, port 3008 dinler.
  Nginx bu porta proxy yapar.


----------------------------------------------------
5) TEST (tarayıcı)
----------------------------------------------------
https://menu.guzelteknoloji.com/api/health
  → {"status":"ok"...} gelmeli

https://menu.guzelteknoloji.com/menu
  → müşteri menüsü

https://menu.guzelteknoloji.com/login
  → admin giriş


====================================================
  HIZLI KOPYALA (sırayla)
====================================================

cd ~/htdocs/menu.guzelteknoloji.com
npm install --omit=dev
npm run setup
npm start


====================================================
  SIK HATALAR
====================================================

EADDRINUSE / port kullanımda
  → Aynı anda hem panel hem npm start çalışıyordur.
  → Birini kapat.

Database / P1000 / auth failed
  → .env içindeki DATABASE_URL şifresi yanlış.
  → ! karakteri %21 olmalı.

Cannot find module
  → npm install --omit=dev tekrar çalıştır.

502 Bad Gateway
  → Node uygulama kapalı / port 3008 dinlemiyor.
  → Panelden Start veya npm start.
